# NetForge

NetForge is an offline-first network engineering toolkit designed for students, network engineers, and cybersecurity learners.

## Features

- IPv4 and subnet calculations
- Cisco configuration generators
- MikroTik RouterOS configuration generators
- Network command library
- Networking references and notes
- Security references
- Favorites and local data storage
- Android APK with offline operation

## Technologies

- React
- TypeScript
- Vite
- Tailwind CSS
- React Router
- Lucide Icons
- Android WebView
- WebViewAssetLoader

## Offline Android App

NetForge can run without an Internet connection because the web application assets are bundled directly inside the Android APK.
